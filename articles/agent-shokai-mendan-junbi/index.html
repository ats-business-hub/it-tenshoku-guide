エージェントの初回面談の前にそろえるものと、聞くこと

公開日（サイト原稿）：2026-11-21　記述の基準日：2026-11-21

広告（PR）について。本記事には、A8.net、バリューコマースなどのアフィリエイト（成果報酬型広告）リンクが含まれます。リンク経由で申し込みや利用があった場合、運営者が紹介料を受け取ることがあります。リンクはテキストのみです。就職、収入、税負担の軽減、投資の利益、最安値などを保証するものではありません。各サービスの対象条件・成果地点・料金は、申し込み前に公式ページで確認してください。

▶ 比べる点と窓口の例は「次のステップ」へ（広告を含みます）

転職エージェントの初回面談（キャリア面談、カウンセリングなど、呼び方はサービスで違います）は、企業の選考面談ではありません。企業のカジュアル面談と選考面談の違いはカジュアル面談と選考面談は、何が違い、何を聞いてよいかを見てください。本記事は、エージェントの担当者との最初の面談の前に、そろえておくものと、その場で確認するとよいことです。初回面談のあとに紹介が始まること、希望に合う求人が出ること、内定は保証しません。

年末年始の登録そのものの準備は年末年始に転職エージェントへ登録するときに、先にそろえておく準備、希望条件の言語化は転職エージェントに伝える希望条件は、年収以外を先に言語化する、1月から3月に活動を始める段取りは1月から3月に転職活動を始めるとき、先に書き分ける段取りを見てください。こちらは、予約が入ったあとの、面談前の確認です。

面談の前にそろえるもの

  1. 職務経歴書または、それに代わる経歴のメモ。 完成していなくても、担当が質問できる粒度があると、初回の時間が書類の穴埋めだけになりにくいことがあります。書き方は職務経歴書は、プロジェクトをどの粒度で書くかを見てください。機密と権利はスキルシートと公開ポートフォリオで、機密と権利を先に見るを見て、出せない情報は外します。
  2. 希望条件のうち、外せないものと、調整できるもの。 年収の数字だけを先に置くと、業務内容や働き方の話が後回しになり得ます。
  3. いまの退職と、入社可能時期の見込み。 就業規則上の申し出の期間、引き継ぎ、有給、賞与の支給日など、自分が把握している範囲で構いません。確定していないことは、確定と伝えないでください。夏の賞与を見る場合は夏のボーナスの支給条件を、1月から3月に退職日を考える前に確認するもあります。
  4. 連絡してよい曜日、時間帯、手段。 在職中の取り方は在職しながら転職活動するとき、面談日程と連絡手段を先に決めるを見てください。
  5. そのサービスに聞きたいこと。 次の見出しに例を置きます。口コミだけを根拠にしないでください。見方は転職エージェントの口コミを見るとき、いつの情報かと対象職種を確認するにあります。

初回面談で確認するとよいこと

担当者は、経歴の確認と、希望の聞き取りを同時に進めることがあります。紹介を急ぐ説明があっても、その場で応募する必要はありません。次を、メモできる形で聞いてください。答えの内容はサービスと担当で違い、この記事では一般化しません（未確認）。

  • 自分の経験領域（例：社内SE、受託開発、インフラ）を、その担当やチームが扱っているか
  • 求人の紹介の進め方。非公開求人の扱いを聞く場合は転職エージェントの「非公開求人」は、何が非公開で、応募前に何を確認するかも参照してください
  • 応募の可否を、自分が確認してから進める手順があるか
  • 他のサービスとの併用を、どのように共有してほしいか。連絡の食い違いは複数の転職エージェントを併用するとき、連絡で食い違いを防ぐ方法
  • 連絡の頻度と、使ってよい手段、時間帯
  • 担当が変わる場合の、引き継ぎの有無

広告（PR）。初回面談の予約や登録の窓口の一例として、社内SE転職ナビ、TechGo、IT専門転職エージェント＠PRO人、転職エージェントの一例であるリクルートエージェント（公式）があります。面談の前に、市場価値診断や求人の探し方を確認する一例として、ミイダス（無料会員登録）の公式ページもあります。いずれも一例であり、推奨ではありません。登録や面談をすれば紹介が始まる、希望の条件に合う、内定が出る、ということは保証できません。各サービスの初回面談の形式、所要時間、必要な書類は、この記事では未確認です。公式案内で確認してください。

伝えない方が安全なこと

  • いまの勤務先の、社外に出せないシステム構成、顧客名、未公開の計画
  • 他社の選考状況のうち、相手が特定できる過剰な詳細（併用の共有は、必要な範囲に留める）
  • 確定していない退職日を、確定した日として伝えること
  • 年収の希望だけを繰り返し、業務内容の希望を後回しにすること

面談の内容は、後から自分でも書き残してください。口頭の「求人が多い」「すぐに紹介できる」は、件数や職種の根拠を確認するまで、判断材料としては弱くなります。

チェックリスト

  • 経歴のメモまたは職務経歴書を、出せる範囲で用意した
  • 外せない希望と、調整できる希望を書き分けた
  • 入社可能時期のうち、確定していることと、未確定なことを分けた
  • 連絡してよい時間帯と手段を決めた
  • 担当の専門領域、紹介の進め方、併用時の共有方法を、質問として書いた
  • その場で応募しない選択があることを、自分で確認した

よくある質問

職務経歴書が未完成でも、初回面談を受けてよいですか。

受けられるかは、サービスの案内によります（未確認）。未完成でも、経歴の骨格と希望条件があれば、不足をその場で確認できることがあります。完成前に登録する場合の注意は、年末年始に転職エージェントへ登録するときに、先にそろえておく準備も参照してください。

初回面談で求人を紹介されたら、その場で応募した方がよいですか。

その場で応募する必要はありません。求人票の言葉、担当範囲、入社時期、年収の内訳を、自分で確認してからで構いません。求人票の用語は求人票の「自社開発」「プライム」「SES」は、何を確認すればよいかを見てください。急いだ方が有利かは、この記事では書きません。

企業のカジュアル面談と同じ準備で足りますか。

足りるとは限りません。エージェントの初回は、希望の整理と、サービスの進め方の確認が中心になりやすい一方、企業のカジュアル面談は、その会社の仕事を聞く場です。場の違いはカジュアル面談と選考面談は、何が違い、何を聞いてよいかを見てください。

まとめ

  • エージェントの初回面談は、企業の選考とは別の場として準備する
  • 経歴、希望、入社可能時期、連絡手段を、出せる範囲で先にそろえる
  • 紹介の進め方と、その場で応募しない選択を、自分で確認する
  • 紹介の開始、希望との一致、内定は保証しない
  • 最新情報は各サービスの公式案内でご確認ください

次のステップ：公式ページで確認する

申し込みや予約の前に、次の点を公式ページで見比べてください。
