エージェントと選考

希望条件の伝え方、複数社の併用、面談の種類。

  • カジュアル面談と選考面談は、何が違い、何を聞いてよいか
    カジュアル面談と選考面談の違い、聞いてよいことと、評価につながる話し方の注意点を整理します。内定の保証はありません。
  • 転職エージェントに伝える希望条件は、年収以外を先に言語化する
    エージェントに希望を伝えるとき、年収だけでなく、業務内容、働き方、外せない条件を整理する観点をまとめます。希望どおりの紹介は保証しません。
  • 複数の転職エージェントを併用するとき、連絡で食い違いを防ぐ方法
    複数のエージェントを同時に使う場合の、応募先の重複、選考状況の共有、辞退の伝え方を整理します。併用の成功は保証しません。
  • 転職エージェントの「非公開求人」は、何が非公開で、応募前に何を確認するか
    転職エージェントの非公開求人について、何が非公開なのかと、応募前に確認する項目を整理します。良い求人や内定は保証しません。
  • 在職しながら転職活動するとき、面談日程と連絡手段を先に決める
    在職中の転職活動で、面談日程の取り方と、連絡手段の分け方を整理します。日程の調整や選考の通過は保証しません。
  • 年末年始に転職エージェントへ登録するときに、先にそろえておく準備
    年末年始に転職エージェントへ登録する前後で、先にそろえておく書類と伝え方を整理します。紹介や選考の開始は保証しません。
  • 転職エージェントの口コミを見るとき、いつの情報かと対象職種を確認する
    転職エージェントや求人サービスの口コミを登録前に見るとき、投稿の時期、対象の職種、担当者個人の話かを確認するための案内です。紹介や内定は保証しません。
  • 1月から3月に転職活動を始めるとき、先に書き分ける段取り
    1月から3月に転職活動を始めるとき、入社月の逆算とは別に、希望条件、書類、年度末の勤務予定を先に書き分ける案内です。紹介や内定、希望月の入社は保証しません。
  • エージェントの初回面談の前にそろえるものと、聞くこと
    転職エージェントの初回面談の前に、経歴、希望条件、入社可能時期、連絡手段をそろえ、紹介の進め方を確認するための案内です。紹介や内定は保証しません。
  • IT転職のオンライン面接で、接続・画面共有・話し方を事前に確認する
    IT職種の転職では、カジュアル面談から最終面接まで、オンラインで行われることが増えています。使うツールの確認、回線と機材、画面共有で見せる資料の機密、つながらないときの連絡先など、面接の前日までに確認する点を整理します。内定や合格は保証しません。
  • IT転職で選考や内定を辞退するときの連絡のしかた。エージェント経由と直接応募で分けて考える
    転職活動で複数の会社に応募していると、選考の途中や内定のあとで辞退することがあります。辞退を決めたら早めに連絡する理由、エージェント経由と直接応募での連絡先の違い、メールの書き方の例、辞退の理由の伝え方を整理します。円満に進むことは保証しません。
